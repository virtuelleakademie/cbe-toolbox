# Soft-Skill Scaffolding: Structural Anchors for Teamwork, Feedback and Self-Regulation

## Summary

Soft-skill goals (teamwork, feedback, self-regulation, interdisciplinary communication) develop only when the design provides a structural anchor that makes the skill practicable and observable; "organic emergence" without an anchor is a design gap, not a plan.

## The anchor principle

Naming a soft-skill goal does not scaffold it. A soft skill becomes practicable —
and assessable — when the design embeds a concrete structure that the learners act
through. The skill flags a soft-skill goal stated without any anchor and proposes
options from the catalogue below; it acknowledges (and does not over-propose) when
an anchor is already stated.

## Structural-anchor catalogue

| Soft-skill goal | Candidate structural anchor |
| --- | --- |
| Teamwork / collaboration | Team charter; defined roles with rotation (`methodology-004`) |
| Feedback / critique | Feedback-format template; structured peer-review rounds |
| Self-regulation | Goal-setting + reflection rhythm; planning checkpoints |
| Interdisciplinary communication | Discipline-mapping artefact; translation task between fields |
| Conflict-handling | Retrospective rhythm; escalation/decision protocol |
| Peer learning | Reciprocal-teaching slots; explanation-as-deliverable |

Each anchor is a defensible option with a tradeoff, not a prescription. The anchor
also gives the Alignment Check a concrete activity to map against the soft-skill
goal on the goals × activities side of the triad.
